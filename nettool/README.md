# NetTool ζ Feedback

本目录用于 NetTool ζ 的项目级反馈说明。

- 项目仓库: https://github.com/SilentCodeTeams/nettool
- 状态: Active
- 适用: 缺陷、功能建议、协议解析问题、跨平台问题、文档问题

## 提交方式

请在 [SilentCodeTeams/feedback](https://github.com/SilentCodeTeams/feedback) 提交 issue，标题以 [NetTool] 开头，或使用反馈模板选择 NetTool ζ。

请提供：

- 版本或 commit
- 操作系统与架构
- 协议与方向（C->S / S->C）
- 复现步骤、期望结果与实际结果
- 相关日志或 pcap 摘要（不要包含敏感数据）

## 安全

安全漏洞请勿公开提交，请发送至 SilentStudio@feedback.email.cn，按 SilentCodeTeams 维护与安全政策处理。
